### 🛡 &nbsp;What I'm building

**[zhidun](https://github.com/zhidun2027/zhidun)** — an Android APK **hardening** tool. It wraps your app in a shell: the original DEX is encrypted and hidden in `assets`, then restored at runtime by a `StubApp` and a native engine (`libjiaguo.so`). One command runs **decompile → encrypt → inject → align → re-sign**.

- 🔒 &nbsp;DEX encryption · custom stream cipher, a fresh key per build
- ⚙️ &nbsp;Native engine across 4 ABIs (arm64-v8a · v7a · x86_64 · mips64)
- 🧬 &nbsp;Anti-debug (`TracerPid`) · root / Xposed / proxy / VPN detection
- ✍️ &nbsp;Re-signs with apksig — v1 / v2 / v3
- 🌐 &nbsp;Fully documented & auditable — [website](https://zhidun2027.github.io/zhidun/) · no black box
